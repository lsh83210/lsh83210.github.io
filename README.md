# lsh83210.github.io

Personal academic homepage of Sanghyun Lee.

Built with [Jekyll](https://jekyllrb.com/) and [Tailwind CSS](https://tailwindcss.com/).
Template adapted from [keunhong/keunhong.github.io](https://github.com/keunhong/keunhong.github.io)
([CC BY-SA 4.0](http://creativecommons.org/licenses/by-sa/4.0/)).

## Local development

```bash
bundle install
bundle exec jekyll serve
```

Open http://127.0.0.1:4000/.
